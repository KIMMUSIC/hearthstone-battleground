# Hearthstone Battlegrounds AI

하스스톤 전장의 구매·판매·배치 같은 의사결정을 학습하는 AI 프로젝트다. 게임 환경을 직접 구현하고, 강화학습과 모방 학습으로 정책을 학습·평가하고 있다.

[개발 기록 — 하스스톤 전장 AI 만들기(1)](https://kimmusic.github.io/project/hearthstone-battleground-ai-1/)

## 목표

- 전투와 상점 규칙이 정확하고 같은 조건에서 결과를 재현할 수 있는 학습 환경을 만든다.
- 당장의 보드 강화와 이후 순위 사이의 지연 보상을 학습하는 정책을 만든다.
- 여러 seed와 다른 상대 구성에서 평가해, 특정 조건에만 맞춘 개선인지 확인한다.
- 제한된 환경에서 검증한 뒤 카드 효과와 상대 구성을 넓힌다.

## 현재 진행 상황

Python 게임 엔진과 Gymnasium 환경을 분리하고, 행동 마스크를 사용하는 PPO 학습을 연결했다. 현재는 상점 카드 7종, 소환 토큰 1종, 2티어를 지원하며 공유 카드 풀과 탈락 처리가 있는 제한된 8인 로비를 구현했다.

작은 고정 상대 환경에서는 PPO 학습 설정 변경으로 생존율이 개선됐다. 8인 로비에서는 아직 휴리스틱 기준선을 넘지 못해 Behavior Cloning으로 행동을 학습하고, 교사 데이터와 모델이 직접 방문한 상태 사이의 분포 차이를 분석하고 있다.

다음 실험은 기본 교사 상태와 추가 방문 상태의 배치 구성 비율을 바꿔 비교하는 것이다. 학습 정확도와 실제 경기 순위를 함께 보고 후보를 판단한다.

실제 게임 클라이언트를 조작하는 프로그램이나 최신 전장 전체를 재현한 엔진은 아니다. 현재 성적은 구현한 제한 환경의 평가 결과다.
