## 선택한 최우선 문제

최우선 문제는 **상대 다양화 자체가 성능 개선 후보가 아니며, 특히 `diverse-v1` 최종 정책이 행동 예산을 낭비하는 방향으로 흔들린다**는 점이다. 지금 증거만으로 전투 규칙 결함을 바로 수정할 근거는 부족하다. 반대로 정책 선택 trace와 감사 수치는 정책/학습 설정 문제를 먼저 좁히라고 가리킨다.

사전 채택 기준은 `mean_delta >= 0.25`, 양성 seed 2개 이상, 생존율 하락 5%p 이하였다. 실제 결과는 다음과 같다.

`scripts/selection_probe.py`는 모델 분포가 action mask를 위반하면 오류를 내고, `scripts/audit_diversity_009.py`도 trace별 선택 action, mask, 확률 합, 불법 action 확률을 재검산한다. 감사가 통과했으므로 지금 단계의 결론은 “불법 action 실행”이 아니라 “합법 action 중 나쁜 반복 선택”이다.
