## 기준 설정 결정

`fixed-v1`을 다음 연구 기준선으로 유지한다. `diverse-v1`은 평균 보상, seed 일관성, 생존율 기준을 모두 통과하지 못했다.

| 기준 | 요구 | 실제 |
| --- | --- | --- |
| 평균 delta | `>= 0.25` | `-1.4194444444444443` |
| 양성 seed | `>= 2` | `0` |
| 생존율 하락 | `>= -0.05` | `-0.17500000000000004` |

이는 “다양한 상대를 넣으면 바로 좋아진다”는 가설을 접는 결정이지, 상대 다양화 구현 자체가 불필요하다는 뜻은 아니다. 구현은 비교 가능한 실험 장치로 남긴다. 다만 다음 주의 기본 학습·평가 기준은 `fixed-v1`이다.

## 현재 최우선 리스크

가장 큰 리스크는 카드 풀이 부족해서가 아니라, 현재 정책이 합법 action 안에서 행동 예산을 낭비하는 쪽으로 수렴할 수 있다는 점이다. 9/11 trace 분석에서 diverse 최종 정책은 stochastic 평가 기준 평균 행동 수와 리롤 수가 늘었고, 일부 argmax pair는 forced end turn과 생존 실패로 무너졌다.

따라서 다음 주에는 확장 전에 다음 원칙을 둔다.

- 정책 결함이 작은 회귀 테스트나 trace 재현으로 잡히면 카드 확장보다 먼저 수정한다.
- 단순히 카드 수를 늘려서 성능 저하를 덮지 않는다.
- 새 대규모 학습은 `FOLLOWUP_010`의 진단과 필요한 소규모 수정 판정 전에는 시작하지 않는다.

## 2주 확장 범위

첫 확장 후보는 **골렘 일반 카드의 단순 죽메 소환**으로 제한한다. 공식 Blizzard API 확인 결과는 `96763 -> 96764` 단순 2/1 소환으로 기록한다. 필요한 성질은 작다.

- 전투 중 일반 골렘 `96763` 사망 시 토큰 `96764`를 빈 보드 슬롯에 소환한다.
- 즉시 공격, 공격자 재선정 특수 규칙, 여러 단계의 전투 중 선택을 요구하지 않는다.
- 기존 사망 처리, 보드 용량, 소환 위치, seed 재현 테스트로 닫을 수 있어야 한다.
- 황금 처리와 상점 등록은 9/16 이후로 미룬다. 9/13-9/15는 연구용 전투 fixture의 일반 골렘만 우선한다.

뱃사람 즉시 공격 계열은 보류한다. 이 효과는 전투 중 소환된 하수인이 즉시 공격하는 순서와 다음 공격자 선택을 건드리므로, 현재 정책 결함과 기본 사망/소환 테스트가 정리되기 전에는 범위를 키우는 효과가 크다.

라이브 패치 기준은 아직 주장하지 않는다. 9/13에서는 카드·효과 후보의 출처를 확인하고, 현재 실험용 엔진에서 재현 가능한 좁은 규칙 계약만 확정한다.
