# 2026-09-27 — 8인 상태와 규칙 계약

상태: **완료 — 설계 계약**. 실제 수행일2026-09-06. 엔진 구현 완료와 구분한다.

선행9/26은 후보 없음 분기로 완료했다. 024 감사에서 학습 설정 외 엔진·데이터·규칙은 이전 검증본과 같았다. 정책이 약하더라도 명시한 엔진 범위의 회귀 검증은 통과했으므로8인 개발을 진행한다.

[8인 계약 v1](../LOBBY_CONTRACT.md)에 공식 출처와 확인하지 못한 영역을 구분했다.8인·모집/전투·기초 경제는 Blizzard 자료를 근거로 삼는다. 정확한 최신 매칭·티어별 재고·동시 탈락 순위·피해 상한은 재현을 주장하지 않으며 연구용 결정을 명시했다. 영웅·방어도·주문·미지원 효과는 포함하지 않는다.

상태 소유자는 별도 LobbyGame이며8개 PlayerState와 SharedPool을 관리한다. 기존 Game.step은 변경하지 않는다. 모집 시작 좌석을 매 라운드 회전시키고 각 좌석이 모집을 마친 뒤 다음 좌석으로 넘어간다. 전체 모집 종료→보드 스냅샷→모든 전투 계산→동시 HP 적용→탈락 반환/순위→종료 또는 다음 라운드로 전이한다.

수기 전이 기대값:

- 8명에서3명 동시 탈락:5명 생존, 탈락자는6·7·8위의 평균7위. 다음 라운드는5명이므로 유령전1개와 실제 대전2개다.
- 5명에서2명 동시 탈락:3명 생존, 새 탈락자는4.5위. 과거7위3명은 변하지 않는다.
- 3명에서2명 동시 탈락:마지막 생존자는1위, 새 탈락자는2.5위. 전체 순위 합은1+2×2.5+2×4.5+3×7=36이다.
- 상한에서3명 생존:terminated=False,truncated=True, 생존자 rank=None. 실제 확정된 탈락 순위만 유지한다. 상한 때문에 임의 승자를 만들지 않는다.
- 이미 탈락하거나 현재 모집 순서가 아닌 좌석의 행동은 상태 변경 전에 오류다.

정책에는 자기 상태의 frozen view와 좌석순 공개HP·티어·생존·순위만 제공한다. 상대 손패·상점·발견·현재 보드와 풀 재고, 내부 엔진 객체는 전달하지 않는다. 감사 trace는 정책 입력이 아니다. 관측 helper는 이 view만 받아 player9, public8×4, 상점7/보드7/손패10/발견3의18폭 슬롯, 행동 마스크37을 만든다. 음수HP·황금·도발·천보·남은행동·스왑·동결·라운드·좌석을 구분한다.
