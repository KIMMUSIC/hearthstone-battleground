## 최종 범위

용혈족 부관 60628(1티어 2/3 도발), 공허방랑자 96796(1티어 1/3 도발)를 추가한다. 상점 카드 7종과 소환 전용 손상된 골렘 1종이다. 원본 스냅샷과 Blizzard API에서 능력치·텍스트를 확인했다. [공식 응답 원본](2026-09-17-official-response.json)을 보존한다.

중간 v3에서 추가된 경비로봇 49278(BOT_218t)과 은빛 새끼 거위 108715(BG29_801t)는 각각 순찰용 부릉이 48100과 은빛 거위 107865가 소환하는 토큰이다. techLevel은 상점 등장 근거가 아니므로 활성 풀에서 제거했다. 103652는 이미 지원하는 안녕로봇 2053의 다른 버전 ID이므로 새 카드 수 달성을 위해 중복 등록하지 않는다. 원본 부모 카드 텍스트가 토큰 관계를 뒷받침한다.

따라서 10–20종 조건부 목표 대신 검증된 7종을 채택한다. 누락된 나머지 후보는 미지원 피해 반응 소환·즉시공격·황금 효과가 필요하다. 단순 카드를 더 찾지 못했다는 이유로 토큰을 상점 카드로 바꾸거나 같은 카드를 중복 집계하지 않는다. 골렘 황금과 뱃사람 즉시공격은 계속 보류한다.

archival-subset-v4 / card-mapping-v4 / onehot-slots-v4. 기존 인덱스 1–6 보존, 60628→8, 96796→9. 중간 진단에서 배정한 7·10·11은 비활성 예약 슬롯으로 남겨 재사용하지 않는다. 슬롯 폭 18, 행동 37개 유지. 생성·관측은 예약된 미등록 ID도 거부한다.

단순 지원 카드의 황금은 base ID + golden 상태와 연구용 스탯 2배 규칙을 유지한다. 모든 실제 황금 레코드를 확인했다는 주장이 아니다. [규칙 계약](../RULES.md)을 따른다.
