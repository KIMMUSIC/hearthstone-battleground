# archival-subset-v4 — 규칙 계약

9/17 최종 기본 풀은 상점 카드 7종과 소환 전용 토큰 1종이다. 토큰을 상점에 넣고 동일 카드의 다른 ID를 새 카드 수로 센 v3 진단안은 교정했다. 일반 골렘 사망·소환은 [연구 계약](DEATH_SUMMON_CONTRACT.md)을 따른다. 009와 폐기된 v3 진단 모델은 현재 계약과 호환되지 않는다.

## 기준과 출처

이 버전은 **특정 라이브 패치를 재현하지 않는 명시적 연구용 부분 규격**이다. 기존 원본 파일에는 확정 가능한 패치 식별자가 없으므로 추측해 붙이지 않았다. 원본 파일의 SHA-256과 선택한 카드 데이터는 `data/cards.json`에 보존한다. 최신 패치·과거 단일 패치의 카드 풀을 재현했다는 주장을 금지한다.

기본 구매·판매·리롤, 왼쪽부터 교대 공격, 도발 대상 우선, 보호막의 첫 피해 차단은 [Blizzard의 2019-11-01 전장 소개](https://hearthstone.blizzard.com/en-us/news/23156373/introducing-hearthstone-battlegrounds)를 참고했다. 아래 표와 제한이 이 버전의 실행 계약이다. 실제 패치 일치 검증은 후속 범위다.

선택은 과거 원본에 보관된 레코드의 효과를 구현할 수 있는지에 따른다. 이름·티어만 보고 현재 상점 등장 여부를 판단하지 않는다. 일반 골렘의 명시적 단순 소환 외 죽메, 함성·환생·독성·종족 시너지·즉시공격은 미지원이다. 미지원 효과를 일반 버프로 대체하지 않는다. 골렘과 토큰의 출처·선정 근거는 연구 계약에 기록했다.

## 명시적인 연구용 제한

- 단일 플레이어 대 고정 상대 보드. 8인 로비·상대 경제·탈락 순위·공유 카드 풀·영웅은 없다.
- 선술집 최대 2티어. 상점은 1티어 3칸, 2티어 4칸이며 관측은 7칸으로 패딩한다.
- 상점은 허용된 이하 티어에서 복원 추출한다. 활성 종족·실제 재고 확률을 모사하지 않는다.
- 초기 HP는 30, 골드는 3. 다음 턴 골드는 min(10, turn+2). 구매 3, 판매 1, 리롤 1. 보유 골드 상한 10.
- 업그레이드는 1→2에 초기 5골드, 매 턴 비용 1 감소. 최대 티어 도달 시 비용 0.
- 손패 10, 보드 7. PLAY는 오른쪽 끝에 배치한다. 인접 SWAP으로 위치 변경, 턴당 3회 제한.
- FREEZE는 토글이며 행동 수를 소비한다. 턴 종료 시 상점 보존 후 다음 턴에 플래그 해제.
- 기본 8턴을 **8번째 전투까지 포함**한다. 이 유한 게임의 정상 종료는 `horizon`, 사망은 `death`다. 외부 학습 시간 예산은 게임 종료와 별개다.
- 일반 행동 한도는 턴당 24. 마지막 행동 뒤 전투를 강제 진행한다. 마지막 행동에서 발견이 열리면 선택을 먼저 끝내고 전투한다. 무한 FREEZE·SWAP 루프는 불가능하다.

## 트리플과 발견

황금이 지원되는 단순 효과 카드는 일반 카드 3장을 모으면 손패·보드에서 제거해 황금 카드 1장으로 합친다. 기본 스탯은 원본의 2배에 기존 추가 스탯 합을 더한다. 황금 카드는 다음 트리플 집계에서 제외한다. 별도 황금 dbfId를 등록하지 않고 원본 카드 ID와 `golden` 상태로 표현한다. 일반 골렘과 소환 토큰은 황금 미지원이므로 트리플에서 제외한다. 골렘 3장은 일반 상태로 유지되고 발견 보상이 생기지 않는다. 이는 미지원 황금 효과를 만들지 않기 위한 연구용 제한이며 실제 게임의 트리플 규칙 재현을 뜻하지 않는다. 미지원 황금 생성 요청은 오류로 거절한다.

황금 카드를 낼 때 3개의 발견 선택지를 별도 모달 상태로 연다. 보상 주문 카드를 손패에 생성하는 실제 흐름은 이 버전에서 생략한다. 선택지는 정확히 min(2, 현재 티어+1) 티어에서 복원 추출하며 중복이 가능하다. 선택한 카드 1장만 손패에 들어간다. 발견 중 다른 행동은 불가하다. 선택지가 관측·액션 영역을 침범하거나 손패를 초과하지 않는다.

## 전투

- 보드 복제본을 사용해 모집 단계 스탯·보호막을 훼손하지 않는다.
- 기물이 많은 쪽 선공, 같으면 시드로 결정. 양측 교대, 각자의 살아 있는 기물을 왼쪽부터 순회한다.
- 사망으로 인덱스가 이동해도 생존 기물을 건너뛰지 않는다. 공격력 0은 자기 공격 순서에서 건너뛴다.
- 도발 중 무작위 대상, 도발이 없으면 모든 생존 적 중 무작위 대상. 양측 피해를 동시에 적용한다.
- 보호막은 양수 피해 한 번만 막는다. 피해 0은 보호막을 소모하지 않는다.
- 패배 피해는 **승자 티어 + 승자 생존 카드 티어 합**이다. 황금도 원본 카드 티어로 센다.
- 양측 전멸은 무승부. 공격 가능한 기물이 없으면 `stalemate`, 방어적 전투 반복 상한은 `combat_limit`으로 구별한다.
- 일반 전투 보상은 승 +1 / 무 0 / 패 -1. 구매·레벨업·함성·트리플 보너스는 없다.

## 상태와 액션

액션 37개: 0 종료, 1 리롤, 2 업그레이드, 3 동결 토글, 4–10 구매, 11–17 판매, 18–27 손패 플레이, 28–33 인접 스왑, 34–36 발견 선택. 실제 정의는 `actions.py`이며 잘못된 액션은 상태 변경 전에 실패한다.

Gym 관측은 player 9개(HP/40, gold/10, tier/2, turn/max_turns, upgrade/5, frozen, actions_remaining/max_actions, swaps_remaining/3, 발견 유무)와 shop·board·hand·discover 슬롯이다. 각 슬롯은 고정 매핑 one-hot(빈칸 포함) + 공격/100, 체력/100, 황금, 도발, 보호막, 티어/2다. 기존 인덱스 1–6을 유지하며 용혈족 부관은 8, 공허방랑자는 9다. v3 진단에서 사용한 7·10·11은 비활성 예약 슬롯으로 보존하고 다른 카드에 재사용하지 않는다. 슬롯 폭은 18, 관측 버전은 onehot-slots-v4다. 매핑에 예약 ID가 있어도 활성 카탈로그에 없으면 생성·관측에서 오류 처리한다. 카드 정체성이 효과와 황금 지원 여부를 결정하므로 별도 효과 플래그를 추가하지 않는다. HP 음수는 허용하되 NaN·무한값은 금지한다.

seed는 게임별 독립 상점·전투 RNG에 전달한다. 동일 런타임·버전·seed·액션열의 재현을 보장한다. 019 실행 검사는 `configs/expansion019_opponents.json`, 020 개발 평가는 `configs/expansion020_dev_opponents.json`을 사용한다. 최종 평가는 `experiments/reserved/expansion020_final_opponents.json`으로 별도 보관하고 이번 실행본·학습 입력에서 제외한다. 단순 카드의 황금 스탯 2배는 이 연구 계약의 경제 규칙이며 모든 실제 황금 카드 ID를 검증했다는 뜻이 아니다.
