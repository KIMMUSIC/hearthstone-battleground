02

만들려는 것은 ‘선택을 배우는 정책’

게임 상태를 숫자로 관측하고, 가능한 행동 중 하나를 고른다. 플레이 결과로 선택 확률을 갱신한다.

개발 방향: 규칙 검증 → 고정 기준선 → 한 변수 비교 → 새로운 평가 조건 → 카드·상대 확장.

학습 파이프라인을 조금 더 자세히

PPO는 수집한 행동·보상으로 정책과 가치 함수를 학습한다. 행동 마스크는 불법 행동의 확률을 제거한다. 현재 8인 로비의 후속 실험은 휴리스틱 행동을 정답으로 쓰는 모방 학습이다. 해당 실험의 지도 업데이트 수를 PPO 환경 스텝으로 세지 않는다.

근거: 설계 결정 · 규칙 계약 · 모방 학습 명세

‘학습이 전혀 안 됐다’는 뜻은 아니다. 잘못되거나 단순화된 환경에서 오른 보상을 목표 게임의 실력으로 해석하기 어려웠다는 기술적 판단이다. 아래는 기존 코드를 읽어 확인한 원인 후보이며, 각 결함이 점수에 미친 기여도를 분리한 실험은 없다.

레거시는 읽기 전용으로 보존한다. 파일·라인 근거는 초안 근거표에 정리했다. 과거 WORK 문서의 학습 해석을 새로운 검증으로 재사용하지 않았다.

05

학습량보다 먼저, 업데이트 방식을 비교했다

512 → 2,048 → 8,192스텝만 늘려서는 안정적인 개선이 없었다. 다음에는 학습 데이터의 반복 사용 횟수(epoch)를 1 → 4로 바꿨다.

새로운 평가 조건에서의 생존율

작은 고정 상대 환경 · 8,192스텝 · 확률적 행동 선택
+71.67%pepoch 1 대비 개선. 휴리스틱에는 미달.

모델 막대당 3 학습 seed × 3 정책 seed × 20 게임 seed = 180회. 휴리스틱은 20회. 같은 게임 seed를 반복 사용하므로 180개의 독립 seed가 아니다.

이 그래프는 작은 환경의 생존율이다. 8인 로비 상위 4위 비율이나 실제 전장 승률이 아니다. epoch 4는 동일 스텝에서 최적화 계산을 더 사용하므로 동일 연산량 비교도 아니다.
실험 조건 · 전체 결과 · 집계 데이터

학습 seeds 7/17/27, 평가 seeds 301–320, 정책 seeds 11/22/33. 새로운 seed 조건과 상대 변경 조건은 같은 20개 게임 seed를 공유한다. 상대 변경은 턴별 보드 수와 tier를 유지하고 카드 구성·순서를 바꿨다. 전체 1,040회는 argmax와 무작위 평가까지 포함한 수이며 각 막대의 분모가 아니다.

상대 변경 조건의 epoch 4 생존율은 73.33%, epoch 1은 0%, 휴리스틱은 100%. 결과는 제한된 세 학습 seed의 기술 통계이며 유의성이나 실전 일반화를 입증하지 않는다.

현재 진행 상황과 실패에서 얻은 다음 질문

045는 기본 교사 데이터 10,752행에 모델별 방문 상태 7,355 / 7,257 / 7,439행을 추가했다. 같은 32×32 MLP, batch64, 모델당 1,024 지도 업데이트로 비교했다. 6모델 합계 6,144 지도 업데이트, PPO 스텝은 0이다.

평균 상위 4위 비율은 1.67% → 5.00%로 올랐지만 평균 순위는 악화했고, 개선 seed는 1/3이며 후보 2개가 교사 dev 정확도 75% 미만이었다. 따라서 미채택 판정을 유지했다.

후속 046에서 2/3 seed는 추가 상태 정확도가 오르는 동시에 기본 교사 상태 정확도가 떨어졌다. 이는 학습 코퍼스의 정확도 비교이며 성능 지표와 별개다. 데이터 출처 사이의 학습 상충을 의심할 근거지만 원인을 확정한 것은 아니다.
