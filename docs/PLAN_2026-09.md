## 목표와 일정 가정

장기 목표는 명시한 전장 규칙과 카드 범위에서 완전한 경기를 시뮬레이션하고, 다양한 상대에게 성능을 검증한 AI를 만드는 것이다. 실제 클라이언트 연동은 시뮬레이터와 정책을 검증한 뒤 별도로 진행한다.

이번 4주의 목표는 **소규모 학습 검증에서 벗어나, 지원 범위가 명확한 확장 환경과 제한된 8인 경기 실험 기반을 확보하는 것**이다. 전체 카드·모든 영웅·최신 패치 대응과 실전 수준 완성을 9월 완료로 약속하지 않는다.

아래 날짜는 매일 개발 세션을 이어갈 수 있다는 가정의 작업 배치다. 상시 실행 예약이 아니며, 날짜 도달만으로 학습이나 앱 작업을 시작하지 않는다. 완료 기준을 통과하지 못하면 후속 단계 날짜를 뒤로 이동한다. 특정 날짜의 성능 개선은 보장하지 않는다.

## 일정 변경과 역할

- Codex: 구현·테스트·실험 명세·번들·로컬 실행·자원 감시·결과 분석을 담당한다.
- Grok Bot: 과거 원격 실행과 진단 기록의 출처로만 남긴다. 현재 계획은 Grok Bot 응답이나 검토 복구를 기다리지 않는다.
- 사용자가 이미 지정한 자원과 실행 범위는 유지한다. 이 일정표가 새 유료 장비나 장시간 실행의 자동 승인을 뜻하지 않는다.
- 테스트 실패·규칙 불일치·호환성 오류는 다음 학습보다 먼저 해결한다. 밀린 작업은 후속 일정과 함께 재배치한다.
