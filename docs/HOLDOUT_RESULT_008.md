# 새로운 seed·상대에서의 학습 없는 검증

2026-09-05 Grok Bot의 기존 Linux CPU 환경에서1040게임 평가를 완료했다. **새 seed만 적용한 조건과 상대 구성을 바꾼 조건 모두에서 epoch4의 평균 개선이 유지됐다.** 따라서 epoch4를 작은 환경의 연구 기준선으로 유지한다. 실전 플레이나 카드·효과 확장까지 검증한 결과는 아니다.

## 고정 조건과 결과

게임 seeds301–320은 이전201–220과 겹치지 않는다. fresh-seeds는 기존 상대를 유지하고, shifted는 턴별 보드 수·상대 tier를 유지하면서 카드 구성과 순서를 변경했다. 두 조건은 같은20개 seed를 사용하므로 독립 평가 seed40개로 세지 않는다. 상대 원문과 모델 경로·해시는 전달 ZIP의 명세에 평가 전에 고정했다.

기존 epoch1/4 각각 학습 seeds7/17/27의8192스텝 모델을 모두 사용했다. 조건별 모델480게임 및 휴리스틱·무작위40게임, 총1040게임이다. 추가 학습은0스텝이다.

## 판정과 현재 단계

사전에 정한 두 조건의 평균 보상·생존율 개선 기준을 충족했다. 작은 환경에서 학습 실행, 설정 비교, 새로운 평가 조건의 재검증까지 한 사이클을 완료했다. 휴리스틱에는 미달하며 새로운 카드·효과·실제 전장에 대한 일반화나 통계적 유의성을 주장하지 않는다. 세 학습 seed와 제한된 상대 구성이 이번 결론의 범위다.

`../configs/research_train.json`에8192스텝·epoch4·rollout32·batch32·CPU1·60초 설정을 저장했다. seed7은 단일 실행의 기본값이며 최선 모델 선정이라는 뜻이 아니다. 비교 실험은 계속7/17/27을 함께 사용한다. 기존 smoke 설정과 snapshot003 소스는 그대로 보존했다.

## 검증과 운영 증거

- `../scripts/holdout_eval.py`: 여섯 모델 해시와 학습량을 확인한 뒤 평가만 수행한다. 모델 수정·추가 학습은 하지 않는다.
- `../tests/test_holdout_eval.py`: 이전 평가 seed 사용, 후보 누락·중복을 거부한다. 관련 로컬7테스트 통과(5.93초), 클라우드7테스트 통과(2.16초), Ruff 통과.
- 진입기1회, 테스트→Ruff→평가 모두 returncode0, supervisor completed, 잔여 PID 없음. 전체63.570초, 평가 프로세스60.217초, 최대 샘플링 RSS402,726,912bytes.
- CPU intraop/interop1, 전체180초, RSS2GiB 조건 안에서 완료했다. 실행 종료 시 디스크 증가85,651,158bytes로150MiB 미만이다. RSS·디스크는 하드 상한 보장이 아닌 샘플링/측정값이다.
- 전달 파일10개와 snapshot003의44파일 검증 통과. 모델6개의 평가 후 실제 해시도 감사된 baseline의 고정 해시와 일치했다.

## 다음 우선순위

기준선을 보존하고 **학습 상대의 다양성을 넓히는 변경**을 다음 독립 실험으로 준비한다. 현재 `Game` 기본 학습 상대는 아기늑대로봇만1/1/2/2/3/3/4/4마리로 구성돼 있다. 평가 상대보다 좁은 학습 분포가 한계 후보이므로, 보상·카드·액션을 동시에 바꾸지 않고 학습 상대 구성만 비교한다. 이번에 사용한 평가 상대를 학습 데이터로 넣지 않는다.

그 비교에서도 보상·생존뿐 아니라 동결 반복·자발적 턴 종료와 seed 간 편차를 확인한다. 학습 환경 변경은 새 실행본과 새 모델로 수행하고 기존 snapshot003 기준선은 유지한다. 새로운 환경 학습이나 카드 확장은 아직 실행하지 않았다.
