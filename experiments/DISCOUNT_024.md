# 9/24 제한 실험 — 행동별 할인율

상태: 실행 전 명세. 실제 작성일 2026-09-06. 021의 사전 증액 기준 실패 후 고정한다. 원본 프로젝트는 읽기 전용이며 로컬 WSL 감독 환경만 사용한다.

## 근거와 가설

021은 세 seed 모두 개선됐지만 최종 평균 보상 -4.04로 heuristic 3.4와 차이 -7.44다. 100만 스텝 확대 기준 -0.5를 충족하지 않는다. 최종 동결·강제 종료는 모두 0이므로 동결이 현재 성능 격차의 주원인이라고 주장하지 않는다.

`diagnostics/discount-controlled-counterexample.json`은 동일한 전투·HP·비할인 보상에서 동결로 행동 수를 늘리면 gamma 0.99의 할인 손실이 작아지는 반례다. 유한 에피소드 gamma 1.0은 그 특정 유인을 없앤다. 학습 개선 여부는 별개의 경험적 질문이다. 보상·환경·상대·관측·행동·epochs는 바꾸지 않는다.

## 고정 실행

- 조건: control gamma 0.99, candidate gamma 1.0. 동일한 수정 소스에서 모두 새 초기 모델로 시작한다. 021 모델은 재개하지 않는다.
- 학습 seed: 7, 17, 27. seed 순서대로 control, candidate를 실행한다.
- 각 실행 8,192스텝, 총 49,152스텝. n_steps=32, batch_size=32, n_epochs=4, fixed-v1, max_turns=8, max_actions=24. 각 1,024 업데이트를 확인한다.
- 평가: 각 실행 초기·최종 모델을 기존 020 개발 seed 20001–20100과 개발 상대 파일에서 평가한다. 총 1,200게임. 평가 전후 모델 불변, seed별 초기 정책 가중치 동일성을 확인한다.
- 최대 CPU 1 thread, 학습당 60초, 감독 단계당 180초, sampled RSS 2GiB, 전체 출력과 반환 ZIP 합계 1GiB. 누적 학습 360초, 평가 600초, 전체 1,200초. 자동 재시도 없음.
- 최근 021의 실측 학습 420.05초/300,000스텝과 평가 47.35초/900게임으로 단순 비례 추정은 학습 약 69초, 평가 약 64초다. 시작 비용과 짧은 학습의 변동을 포함한 보장값은 아니며 실제 감독 상한을 우선한다.
- 소스·설정·실행기·해시를 고정한 별도 패키지와 비어 있는 run 디렉터리를 사용한다. 최종 holdout은 포함하지 않는다. 실측 카운터·유한 파라미터·감독 종료·ZIP 무결성·trace와 요약을 감사한다.

## 9/25 판정과 9/26 분기

독립 단위는 세 학습 seed다. 모든 seed 결과와 차이를 보고하고 가장 좋은 seed만 선택하지 않는다. gamma 1.0의 제한 실험 지지는 paired final reward 차이 평균 >=0.5, 양수 차이 >=2/3, paired survival 차이 평균 >=-0.05를 모두 충족할 때만 기록한다. 동결·강제 종료·전체 행동 수는 기술 지표이며 사후 임계값을 만들지 않는다.

최종 평가 후보는 위 비교 기준에 더해 candidate의 초기 대비 평균 보상 증가 >=0.5, 양수 seed >=2/3, 생존율 차이 >=-0.05, heuristic 대비 최종 평균 보상 차이 >=-0.5를 모두 충족할 때만 candidate 세 모델 전체를 동결한다. control이나 021의 최고 seed를 대신 승자로 선택하지 않는다. 통과하지 않으면 후보 없음으로 9/26을 보고하고 최종 세트를 미사용 상태로 보존한다. 통과하면 020 최종 명세의 100게임씩 세 모델을 한 번 평가한다. 결과에 맞춰 기준을 변경하지 않는다.

정책 채택 여부와 별개로 엔진 검증을 통과하면 9/27–10/1의 제한된 8인 엔진 개발을 진행한다. 10/2 PPO 어댑터는 현재 범위에 포함하지 않는다.
