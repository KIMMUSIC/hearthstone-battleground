# 10/2 — 8인 학습 경로 smoke 사전 명세

실제 작성일2026-09-06. 선행030의100경기·행동 재현 감사와276테스트 통과를 확인했다. 이번에는 학습 인터페이스만 추가하며 기존 카드·전투·풀 규칙은 유지한다.

- 학습 좌석0, 나머지7좌석 deterministic heuristic. 완전 자기대전은 제외한다.
- 관측은 자기 상태와 공개 상태만,37개 행동 마스크. 환경 버전은 기존 단일 경기와 분리한다.
- 학습자 순위가 확정되면 해당 에피소드를 종료한다. 나머지 경기 완주는 요구하지 않는다. 공동 순위도 동일식 `reward=(4.5-rank)/3.5`, 나머지 행동 보상0. 제한 중단 시 미확정 순위에 보상을 만들지 않는다.
- gamma1.0: 유한 에피소드의 순위 목적을 그대로 사용한다. 기존024 결과를 8인 성능 증거로 인용하지 않는다.
- train seed7, episode seed범위0..9999. 평가20001..20020은 학습에 사용하지 않는다. 기존 단일 환경의 예약 최종 세트는 사용하지 않는다.
- 최대8192 learner transitions, CPU1, n_steps32/batch32/epochs4, 협력적60초. 감독 단계180초·샘플링RSS2GiB·출력+반환ZIP1GiB. 초과 시 중단하고 실제 스텝/업데이트를 보고하며 자동 재시도하지 않는다.
- 새 모델의 초기/최종 checkpoint 각각20개 고정 평가 에피소드, 동일seed heuristic 기준선20개, 최종 모델2개 재현 확인. 학습 후 평가만 수행한다. 평가 모델 해시 불변·유한 가중치·실제 업데이트·환경 서명을 검사한다.
- 측정: 실제 스텝, 학습 경과/처리량, 완료 에피소드·제한 중단, 평균순위·보상·상위4위 비율(공동순위<=4), 행동 수, 감독RSS·종료코드·잔여PID. 제한 중단은 순위 평균에서 제외하고 별도 개수로 보고한다.
- 통과 기준은 실제 업데이트와 호환성 검사, 저장/로드·고정 평가·동일seed 재현, 합법행동·관측 공간·카드 보존·정보 경계 테스트다. 20seed smoke로 성능 우위나 일반화를 주장하지 않는다. 예산 종료로 업데이트가 없으면 미완료로 보고한다.

결과에 따라10/3 감사와10/4 이후 계획을 구체화한다. 후속 계획 작성이 후속 실험 실행 승인을 뜻하지 않는다.
