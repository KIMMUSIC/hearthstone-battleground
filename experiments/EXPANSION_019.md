# 확장 환경 측정 019 — 실행 전 계약

상태: 준비 중. 사용자 승인 범위는 9/17–20이며, 이 실험은 9/19의 짧은 학습 측정이다. 원본 프로젝트와 기존 009 산출물은 변경하지 않는다.

## 선행과 고정 입력

9/17 카드·관측 계약 및 9/18 경제 경계 검증을 통과한 개발 소스를 새 `expansion-019-local-r1` 실행본으로 고정한다. 실제 카드·소스·규칙·매핑 해시와 모든 입력 FILES manifest는 패키지 생성 시 기록한다. 완료된 009 모델을 이어서 학습하지 않는다.

학습 조건은 fixed-v1을 유지한다. 009에서 diverse-v1 채택 기준을 통과하지 못했고, 이번 측정은 카드·규칙 확장 이후의 실행 가능성과 비용을 확인한다. 새 상대 학습 분포를 동시에 비교하는 실험이 아니다.

## 실행 예산

- seed 7, 신규 최대 8,192스텝, rollout 32, batch 32, epoch 4, CPU 1스레드.
- 협력적 학습 시간 60초, 각 감독기 단계 180초, 표본 RSS 2GiB, 출력과 반환 ZIP 합계 1GiB. 이전 실행과 같은 한도를 유지한다.
- WSL Ubuntu의 `/home/hwa3060/hsai-local/venv311/bin/python`을 사용한다.
- 초기 및 최종 모델을 저장·로드하고 각각 20개 고정 seed로 평가한다. 같은 조건의 heuristic/random 각 20게임을 함께 측정한다. 9/20 개발·최종 평가 세트와 별도 seed 범위를 쓴다.
- 입력 무결성 확인, 빈 출력 확인, 단계별 감독기 로그와 잔여 PID 확인, 실제 카운터·최종 모델 해시·출력 크기·반환 ZIP 검증을 완료해야 성공이다.
- 실패 결과를 보존하며 같은 run ID로 재시작하지 않는다. 예상 스텝에 못 미치면 완료량과 이유를 기록하고 필요한 새 실행을 별도로 명세한다.

## 판정과 후속 산정

학습 성능 향상은 이번 측정의 통과 기준이 아니다. 실제 학습·저장·로드·평가·자원 감시가 작동해야 한다. 실행 후 실측 학습 시간/스텝과 평가 시간/게임으로 9/20의 100,000스텝 × 3 seed 계획 상한을 계산한다. 추정치와 허용된 실제 실행 한도를 구분하고, 9/21 학습은 이번 범위에서 시작하지 않는다.
