# 학습 곡선의 첫 측정

우선 seed7·512스텝 한 번만 측정한다. 초기와 최종 checkpoint를 고정 게임 seeds201–220, argmax와 정책 seeds11/22/33 확률적 선택으로 평가한다. 학습512스텝, 총160평가게임이다.

기존 snapshot-003의 소스·규칙·보상·모델 구조·rollout32·batch32·epoch1을 유지한다. 새 출력 위치에서 학습하며 checkpoint_interval만 예산과 같게 지정한다. 초기/마지막 rollout의 업데이트 전/최종 업데이트 후 checkpoint를 보존한다. 평가에는 최종 업데이트 후 모델을 사용하고 내부 optimizer update count=16을 검증한다. 이전 결과를 덮어쓰거나 재개하지 않는다.

기존 Grok venv311, CPU intraop/interop1, 학습 내부60초, 학습+평가 전체 외부180초, 샘플링 RSS2GiB, 추가디스크100MiB. 새 의존성 설치나 기존 파일 삭제는 하지 않는다. 실패 시 후속 실행 중단·증거 반환. 관련 테스트와 Ruff 통과 후 실행한다.

반환값은 순수 train 함수 시간, 전체 감독기 시간, 샘플링 RSS, optimizer 업데이트 수, 학습 손실·KL·엔트로피와 초기/최종의 보상·전투 승률·생존율·동결/턴 종료 비중·정책 확률이다. 시간과 메모리 수치를 확인한 뒤에만 후속 예산을 정한다.

후속 후보는 seeds7/17/27 × 512/2048/8192스텝이다. 이번512 파일은 이후에도 보존하고 같은 작업을 중복 실행하지 않는다. 각 학습량은 초기화부터 새로 학습해 재개에 따른 RNG 재시작을 학습 곡선에 섞지 않는다. 세 학습 seed와 여러 평가 seed는 서로 다른 변동 요인이므로 구분해 보고한다.
