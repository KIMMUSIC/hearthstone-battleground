# 043 — 행동 클래스 균형 샘플링 비교 계획

착수 조건: 042의 보강된 진단과 회귀 검증이 통과하고 결과 문서가 확정된 뒤 실행한다. 현재는 명세이며 실행 결과가 아니다.

041은 행동 모방과 경기 전이의 사전 기준을 모두 통과하지 못했다. 042 예비 진단에서는 학습 데이터의 리롤이5,669/10,752행을 차지하고 행동별 평균 정확도는 약33%다. 전체 일치율이 높은 상태에서도 판매·구매 슬롯 등 드문 행동의 학습이 부족하다. 이는 샘플 분포 비교의 근거이며 원인 확정은 아니다.

## 단일 변경과 예산

같은32×32 모델, h7/fixed-v1 환경, teacher train0..99/dev20001..20020, seed7·17·27을 유지한다. 새로운 고정 실행본에서 데이터와 모델을 만든다. 이전 모델과 실행본을 수정하지 않는다. 각 쌍의 초기 가중치는 같아야 한다.

대조군은 기존 행별 균등 복원추출이다. 후보는 균등 행 샘플링과 균등 행동 클래스 샘플링을50:50으로 섞는다. 학습 데이터에서 관측된 행동 클래스 수K, 클래스별 행 수n_a, 전체 행 수N일 때 각 행의 확률은 `p_i=0.5/N+0.5/(K*n_action_i)`다. 학습 split의 빈도만 사용하고, 표본 없는 행동에는 예제를 만들지 않는다. 개발 데이터는 샘플 확률·optimizer에 사용하지 않는다. 두 조건은 같은 로컬 seed의 확률 샘플링 함수로 실행하여 주된 변경을 확률 분포로 제한한다.

각 모델 Adam0.0003, batch64,1,024업데이트, clip0.5, CPU1·60초. 총6모델·6,144지도업데이트·393,216행 노출. PPO 환경 스텝과 SB3 업데이트는0, critic 불변이다. 균형 샘플링 외에 보상·모델 폭·학습량·상대·관측은 바꾸지 않는다.

샘플 추출은 고정 설치된 NumPy의 `np.random.default_rng(model_seed)`를 모델마다 새로 만들고 매 업데이트 `rng.choice(N, size=64, replace=True, p=probabilities)`로 수행한다. 대조군도 길이N의 명시적 균등 확률을 전달한다. 실제 optimizer에 전달한 행 인덱스를 업데이트 순서대로 shape(1024,64)의 int64 NPZ로 보존하고 해시를 기록한다. 독립 감사는 학습 split과 설정으로 같은 인덱스 배열을 재생성하고 저장된 전행과 비교하며, 그 인덱스에서 계산한 행동 히스토그램도 확인한다.

dataset1+train6+evaluate6+baseline1=14감독 단계. 각180초, 샘플링RSS2GiB, 출력+반환1GiB. 실패한 실행 ID 재사용과 자동 재시도는 하지 않는다.

## 평가와 사전 판정

초기/최종6모델×20경기=240, heuristic/random 각20=40으로 공통평가280경기, 최종2seed 추가재현은총12개다. train/dev 전체 일치율·NLL·표본 있는 행동별 정확도의 단순평균(macro)·혼동 행렬을 함께 보고한다. 모델별 실제 샘플 행동 히스토그램과 지시된 확률을 기록한다.

분류 개선 기준: 개발 macro 정확도의 후보−대조군 평균차≥0.10, 양성seed≥2/3, 각 후보 최종 전체 정확도≥0.75. 전체 정확도만 최적화하면 다수 행동으로 편향될 수 있어 새 비교에서는 macro 개선과 전체 정확도 하한을 함께 사용한다. 이는 041의 기준을 변경하지 않는다.

개발 macro의 분모는 고정 dev.npz의 정답 actions에 실제 등장한 서로 다른 액션 ID 수다. 각 ID의 정답 표본 중 정확히 같은 ID를 예측한 비율을 구한 뒤 단순평균한다. dev 표본이 없는 액션은 제외하며0점을 부여하지 않는다. 모든 모델·조건은 같은 개발 클래스 집합을 사용한다. train macro는 별도로 train에 등장한 클래스 집합을 사용하며 판정에는 넣지 않는다.

경기 개선 기준: 후보의 평균순위가 대조군보다≥0.5위 개선, 개선seed≥2/3, 후보 평균 상위4위 비율이 대조군 이상, 전체 제한중단0. 두 기준을 모두 만족할 때만 균형 샘플링을 후속 후보로 유지한다. 미사용 평가 성능이나 전체 전장 성능으로 표현하지 않는다.

독립 감사는 초기 가중치 쌍 일치, 모든 actor Adam 카운터1,024·critic 불변·PPO0, 학습 데이터만으로 만든 샘플 확률 및 노출 기록, 개발 지표 재계산,280경기 전체 행동 재생, 모델/입력/반환 ZIP 및 자원 검증을 포함한다. 예약 최종 seed는 계속 미사용이다.

두 기준 통과 시 별도 모방 초기화→PPO 비교를 설계한다. 분류만 개선되면 방문 상태 분포 차이를 좁혀 진단한다. 둘 다 미달이면 행동 클래스 균형 가설은 지지되지 않은 것으로 기록하고, 추가 학습량 대신 오류 구조를 다시 확인한다. 카드 확장은 학습 경로가 검증될 때까지 보류한다.
