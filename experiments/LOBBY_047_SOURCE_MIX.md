# 047 — 기본 데이터 비중 고정 비교

상태: 계획 작성·검토 완료, 사용자 요청으로 재개 대기. 구현·실행 미착수. 046의 출처별 정확도 상충 조건을2/3seed로 충족했다. 같은 오류 종류 쌍 집중 조건은 미충족이므로 특정 행동 보정으로 좁히지 않는다. 새로 방문 상태를 수집하거나 데이터 양·모델 크기·업데이트 예산을 늘리지 않는다.

## 가설과 단일 변경

045와 동일한 증강 학습 데이터에서 기본 teacher 상태의 노출 비중을 높이면, 추가 상태 학습을 일부 유지하면서 기본 행동의 정확도와 경기 성능을 회복할 수 있는지 시험한다. 기존 실제 기본 행 노출은seed7/17/27 각각41,878/40,988/37,339회이며 총65,536회 중57.0–63.9%다. 이는 연관 근거이며 원인 확정이 아니다.

대조군은045 candidate의 학습 경로를 그대로 재현한다. 같은seed의증강train에서 기존balanced-choice 확률p로batch64를복원추출한다. 후보는batch마다기본행48개·추가행16개를추출한다. 각출처내조건부확률은대조군p를해당출처확률합으로나눈값으로고정한다. 각출처에서클래스균형확률을새로계산하지않는다. 따라서 주된 비교는출처비중이며두출처내상대확률은같다.

후보는np.default_rng(model_seed)를사용해기본48회choice→추가16회choice→결합64개permutation순으로매업데이트실행한다. replacement=True. 실제인덱스는optimizer입력직전에보존한다. 전체후보노출은기본49,152행·추가16,384행이다. marginal확률은기본영역0.75*p/sum(p_base),추가영역0.25*p/sum(p_added)다. batch구조가다르므로기존choice-probabilities-v1로표시하지않고source-quota-48-16-v1로기록한다. 75/25는이한번의회복가설검증용고정값이며여러비율을탐색하지않는다. 고정quota는batch별출처구성의분산도바꾸므로, 결과는48/16샘플링규칙전체의효과이며평균비중만의순수효과로해석하지않는다.

## 데이터와 구현 경계

runs/lobby-045-local-r1의기본/증강train·dev·manifest·collection을해시와출처를갖춘읽기전용입력으로새패키지에포함한다. 기본prefix와추가행경계,학습seed0..99,dev20001..20020의분리와바이트불변을확인한다. 동일seed의두모델은같은증강파일을사용한다. 수집정책을다시실행하거나이전모델을추가학습하지않는다. 대조군재현대조를위해045 candidate 최종model.zip/metadata.json도출처해시와함께고정입력에포함한다.

현재src19파일은045고정본과동일하게유지한다. scripts의명시적실험학습경로에서source sampler를사용하고기존모델생성·저장·호환검사등을재사용한다. 전역RNG monkeypatch, 기존sampling명세와다른확률을거짓metadata로기록하는방식, compatibility검사우회는금지한다. 필요한학습루프는기존동작과패리티검증을갖춘다.

실행전필수검증: 동일한기존balanced-choice인덱스를사용할때새실험경로와기존train_imitation의초기/최종policy가중치·actoroptimizer·critic·카운터가일치해야한다. 본실험대조군도045 candidate의동일seed 최종policy가중치와일치해야하며, 다르면비율효과를판정하지않는다. 새경로의수치/마스크/gradient검사는기존수준을유지한다.

## 예산·평가·판정

두조건×seed7/17/27=새모델6개, 동일초기가중치쌍. 모델32×32,fixed-v1,h7,Adam0.0003,batch64,clip0.5,1,024지도업데이트,모델당60초,CPU1/1. 총6,144지도업데이트·393,216노출,PPO스텝0,critic불변. 각감독단계180초·샘플링RSS2GiB·출력+반환1GiB,고유run/빈출력/자동재시도없음. 데이터는고정입력이므로control train3→candidate train3→evaluate6→baseline1의13단계다. control3개의045가중치재현을모두확인한후candidate학습을시작한다.

평가는초기/최종6모델×20=240경기,heuristic/random각20=40으로280경기및최종12재현이다. dev는반복개발세트이며최종holdout이아니다. teacher기본/추가/dev분류와최종자기방문상태일치율도분리해서보고한다.

후보유지기준은047대조군대비평균순위≥0.5위개선·개선seed≥2/3·평균상위4위비율비감소·제한중단0,동시에모든후보teacher dev micro≥75%다. 045 teacher-only 결과는참고기준선으로별도보고하며과거판정은바꾸지않는다. 기준을통과해도현재제한환경의개발비교범위이며카드확대나PPO연결의충분조건으로자동해석하지않는다.

분류18개는최종6모델×기본/추가/dev이며초기/최종경기평가는별도다. 독립감사는실제48/16개수와인덱스재생성·조건부/주변확률·데이터불변·초기쌍·기존경로패리티·Adam/critic/PPO카운터·18분류및280경기재현·ZIP/자원을검증한다. 모델/데이터/평가의모든기준을실행전고정한다. 실패하면단순출처비중회복가설을미지지로기록하고다른비율자동재시도는하지않는다.
