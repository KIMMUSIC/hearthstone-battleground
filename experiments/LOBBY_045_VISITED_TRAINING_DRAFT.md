# 045 — 학습 seed 방문 상태 추가 비교 초안

상태: 조건부 초안. 044의 사전 분기(후보의 teacher-dev 대비 자기 방문 상태 일치율 하락≥20%p가2/3seed 이상)를 확인하고 계획 검토를 마치기 전에는 실행하지 않는다.

목적은 teacher trajectory만 배운 정책이 자기 방문 상태의 올바른 행동을 배우는지 확인하는 것이다. 현재 엔진·모델 소스19파일은043고정본과 일치한다. 별도 script에서 데이터를 수집하고 현재 모방 학습 API를 사용하면 모델 호환성 검사를 유지할 수 있다. source를 바꾸거나 기존 모델을 수정하지 않는다.

## 데이터와 단일 변경

043의 seed7·17·27 balanced 최종 모델을 각각 고정 collector로 사용한다. 성능 후보로 채택했다는 뜻이 아니며044에서 진단한 상태 분포를 만드는 수집 정책이다. 실행 패키지에 해당 checkpoint model.zip/metadata.json과 해시·출처를 포함하고 엄격한 환경 호환성 검사를 적용한다.

teacher 기본 데이터는 기존처럼 학습seed0..99의100경기, 개발은20001..20020의20경기다. 각 collector도 학습seed0..99만100경기 실행한다. 매 행동 전 숫자 관측과 같은 상태의 heuristic 정답을 저장하고 실제 환경에는 collector의 합법 예측 행동을 실행한다. 정답과 실행 행동을 구분한다. 제한중단이 있으면 실패 처리한다.

대조군은 teacher 기본 학습 행만 사용한다. 후보는 같은 teacher 행 뒤에 해당 model seed의 collector 방문 상태/teacher 정답을 덧붙인다. 모델3개의 수집 데이터를 서로 섞지 않는다. 각 split의 행 수·seed·수집 정책·원본 모델 해시·trajectory 종류/행 범위를 명시한다. 개발 NPZ는 두 조건에서 바이트가 같고 optimizer와 샘플 확률 계산에 사용하지 않는다. dev 방문 상태를 수집하거나 학습에 넣지 않는다.

두 조건 모두 새 모델을 같은 seed의 같은 초기 가중치에서 학습한다. 043 balanced 샘플링을 고정하여 데이터 출처 변화만 비교한다. balanced가 성능 기준을 통과했다고 간주하지 않으며 새로운 데이터 비교의 진단 대조군으로 명시한다. 샘플 확률은 각 학습 데이터의 실제 label 빈도에서 계산하므로 데이터 변경에 따른 확률 변화는 기록한다.

## 예산과 평가

모델32×32·h7/fixed-v1·Adam0.0003·batch64·1,024업데이트·clip0.5·CPU1·모델당60초를 유지한다. 총6모델·6,144지도업데이트·393,216행노출, PPO스텝0·critic불변. 수집300경기는 환경 실행으로 별도 집계하며 PPO학습량으로 표시하지 않는다.

base dataset1+collect3+train6+evaluate6+baseline1=17감독단계. 각180초, 샘플링RSS2GiB, 출력+반환1GiB. 고유run·빈출력·자동재시도 없음. 수집 기록은 seed별 행동열·rank/reward·trace해시·행범위를 보존하고 독립 감사에서 재생성한다.

초기/최종6모델×20=240경기와heuristic/random각20=40으로280평가·최종12추가재현을 한다. teacher dev 전체/macro/NLL뿐 아니라 최종 자기 방문 상태의teacher일치율도 같은120경기에서 집계한다. 각 지표의 분모와 클래스집합을 명시한다.

사전 후보 유지 기준 초안: 평균순위가 대조군보다≥0.5위 개선·개선seed≥2/3·후보평균상위4위가 대조군 이상·제한중단0, 동시에 모든 후보의teacher dev전체일치율≥75%. 자기 방문 상태의 일치율 변화는 별도 진단 지표로 보고하고 순위 기준을 대체하지 않는다. 041/043 기준에 소급 적용하지 않는다.
