# 040 — 숫자 관측의 정책 정보 충분성

039는 일부 작은 개선만 보였고 채택 기준을 충족하지 못했다. 다음 학습 변경 전에 관측에 좋은 행동을 선택할 정보가 있는지 검증한다.

고정039 소스, fixed-v1 관측과 공개 Catalog만 입력받아 heuristic에 필요한 최소 view를 복원한다. 슬롯의 onehot ID, 공격/체력, 황금/도발/천보, 손·보드·발견의 위치와 합법행동, 골드를 사용한다. 원본 게임이나 원본 view, 다른 플레이어의 비공개 정보를 복원 함수에 전달하지 않는다. 공개 카드 ID별 triple_allowed는 고정 카탈로그에서 조회할 수 있다.

개발seed20001..20020에서 heuristic/random 각20경기와039 최종6모델의 각20개 저장 행동 trace를 재현한다. 총160에피소드의 모든 행동 전 관측에서 복원 heuristic과 원본 view heuristic을 비교한다. 모델을 새로 학습하거나 원래 행동을 복원 heuristic으로 대체하지 않는다. 저장trace의 합법성·보상·전체게임trace 및 입력불변도 확인한다.

판정: 행동 불일치0일 때 조사한 상태에서 관측이 해당 heuristic의 결정에 충분하다는 제한된 증거로 해석한다. 전체 상태공간 증명, 신경망 표현력 증명, 학습 성공이나 새 성능 개선이라고 표현하지 않는다. 불일치는 상태와 행동을 기록하고 이유를 먼저 고친다.

CPU1,180초 이내, 새 의존성·학습·모델 변경 없음. 새 출력 덮어쓰기 거부. 카드/손/발견/보드가 찬 상태와 잘못된 인코딩 테스트, 소스/입력 해시·실측 상태 수·불일치 수를 완료 증거로 남긴다. 미사용 검증 seed는 접근하지 않는다.
