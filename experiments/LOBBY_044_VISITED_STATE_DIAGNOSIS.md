# 044 — 균형 샘플링 후 실제 방문 상태 진단

043 독립 감사가 통과했지만 분류 기준만 통과했다. 개발 macro는평균13.98%p 개선, 경기순위는0.175위 개선·양성seed1/3·상위4위비율감소로 후보미채택이다. 다음 진단은 새 학습 없이 자기 방문 상태의 잔여 오류를 좁힌다.

입력은 runs/lobby-043-local-r1의 고정 소스, 최종6모델, dev teacher2,236행, 최종6×20=120경기 trace다. CPU1, 실행180초 안의 읽기 전용 진단으로 한다. 기존 모델/trace/입력 해시를 전후 비교하고 새 결과 파일만 쓴다.

1. 각 seed/조건의 최종20경기를 재생한다. 매 행동에서 현재 모델예측=저장행동, 합법성·관측·카드보존, 최종rank/reward/trace를 확인한다. 공동 순위도 보존한다.
2. 매 상태에서 기존 heuristic을 teacher로 호출하고 정확히 같은 액션 ID 일치율, 실제 상태의 teacher 클래스별 정확도·표본수·혼동 행렬·macro를 보고한다. teacher 데이터 정확도와 비교할 때 서로 다른 분모와 클래스 집합을 명시한다. 같은 액션 종류의 다른 슬롯 예측을 별도 오류로 집계한다.
3. round1–3/4–6/7이후 구간과 첫 불일치 행동 종류를 집계한다. 모델별 자기 gold/board수/hand수/tier의 평균과 분포를 teacher dev와 비교한다. feature는 자기 공개 상태에서만 계산한다. 경기 길이 차이로 상태 표본수가 달라진다는 제한을 기록한다.

출력은 experiments/diagnostics/lobby044_visited_states.json이며 기존 출력 덮어쓰기 금지. 오류 집계와 구간 분모를 경계 테스트로 고정하고 모든seed를 포함한다. 최종 검증 seed는 사용하지 않는다.

균형 후보의 자기 방문 상태 일치율이 teacher dev보다20%p 이상 낮은 현상이2/3seed 이상에서 남으면, 다음 단계에서 학습seed0..99만으로 모델 방문 상태를 수집해 teacher로 라벨링하는 별도 비교를 명세한다. 이 진단의 dev 방문 상태는 학습에 사용하지 않는다. 차이가 작으면 분류 개선과 경기 성능의 불일치를 행동별로 더 좁혀 다음 단일 가설을 정한다. 상태 분포 차이 자체를 인과관계 확정으로 표현하지 않는다. 카드확대·예산증액은 보류한다.
