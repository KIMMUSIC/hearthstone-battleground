# 038 — 저장 학습 로그의 종국 보상 기여 범위

037에서 초기 포화가 크게 줄었지만 성능은 개선되지 않았다. 다음 변경 전 실제 학습 종료시점으로 보상 전달 범위를 측정한다.

고정 입력은 lobby-037-local-r1의6개 status.json과 최종 model.zip의 gamma/GAE lambda/n_steps이다. 단계 수가 연속인 단일 환경의 episode 종료 num_timesteps로 구간을 복원한다. 실제 n_steps32에서 각 transition이 같은 episode 및 rollout 안의 종국 보상에 직접 연결되는지, 그 계수 `(gamma*lambda)^distance`와 실제 종국 보상을 곱한 절댓값을 집계한다. rank4.5의 보상0도 구분한다. 미완료 마지막 episode는 기록 밖의 종국 보상을 추측하지 않는다.

같은 저장 trajectory를 가상 rollout128/256으로 재분할한 수치는 반사실 구조 진단일 뿐 학습 성능이나 실제 새 rollout의 결과가 아니다. λ1의 동일 구간 계수도 별도 비교할 수 있다. 전체 GAE는 가치 함수 TD 항과 bootstrap을 포함하므로 직접 reward 기여가0인 구간을 학습 신호가 완전히0이라고 표현하지 않는다.

학습·모델 수정·새 게임 실행 없음. 입력/model 해시와 불변 확인, 새 출력 덮어쓰기 거부, 작은 수작업 예제의 경계·종료보상0·미완료구간 테스트를 완료 기준으로 한다. 진단 결과로 자동 예산 증액이나 여러 하이퍼파라미터 동시 변경을 하지 않는다.
