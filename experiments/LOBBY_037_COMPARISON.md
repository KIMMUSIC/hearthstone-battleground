# 037 — 고정 관측 스케일 단일 변수 비교

## 근거와 가설

036의 2,236개 공통 heuristic 관측에서 초기 정책 첫 Tanh 포화 비율은 58.56–60.12%, 최종은 74.82–82.32%였다. player/public 필드는 최대30, 카드 필드는 최대1이었다. 이는 고정 스케일 조정을 시험할 근거이며 인과 확정은 아니다.

가설: player/public 수치의 고정 단위 조정이 과도한 초기 포화를 줄이고 같은 예산에서 공통 평가 성적을 개선한다. 035의 혼합 상대 구성은 채택된 우수 정책이 아니지만 순위 분산을 제공했다. 이번 두 조건 모두 heuristic3/random4로 고정해 보상 신호가 있는 조건에서 스케일만 비교한다.

## 단일 변경과 보존 계약

대조군 observation_scale=raw, 후보=fixed-v1. player의 [seat,round,hp,gold,tier,upgrade_cost,frozen,actions_remaining,swaps_remaining]을 각각 [7,100,30,10,2,5,1,24,3]으로 나눈다. public의 [hp,tier,alive,rank]는 [30,2,1,8]로 나눈다. 상수는 규칙의 단위이며 데이터 통계를 학습하지 않는다. 클리핑하지 않아 음수 HP나 큰 값의 정보를 보존한다. 카드 슬롯·행동 마스크·정보 공개 범위·상태 전이·보상·상대 정책은 동일하다.

버전과 스케일 계약은 체크포인트 서명에 저장한다. 관측 스케일 불일치는 로드 전에 거부하고 명시적 상대 이동 허용으로 우회할 수 없다. 구형 모델은 기존 frozen source에서만 분석한다.

## 예산과 평가

seed7·17·27, 두 조건 각8,192스텝/1,024업데이트, 총49,152스텝. n_steps32,batch32,epochs4,gamma1,GAE lambda0.95,학습상대3heuristic/4random,좌석0,최대100라운드. 같은 seed의 초기 가중치는 일치해야 한다. 학습 게임 seed0..9999.

공통 평가 게임은 heuristic7 상대와 개발 seed20001..20020. 각 모델의 초기/최종20회=240, heuristic/random 기준선 각20회=40, 총280회. 최종 모델은 첫2seed를 추가 재현한다. 각 모델은 자기 스케일로 동일한 게임 정보를 인코딩하며 raw/scaled 모델을 서로 다른 관측에 잘못 적용하지 않는다.

CPU1, 개별학습60초, 감독180초, 샘플링RSS2GiB, 출력과 반환1GiB. 입력을 새 run에 동결하며 자동 재시도와 기존 run 재사용은 금지한다. 예약 검증22001..22100 및 기존 최종 세트는 미사용 유지.

## 사전 판정

성능 채택은 모두 필요하다: 평균 대조군−후보 순위 개선≥0.5, 3seed 중 최소2개 개선, 후보 초기→최종 평균 개선≥0.5, 상위4위 비율 비감소, 제한 중단0. 모든 seed를 보고한다. 기존035 기준을 그대로 사용한다.

수치 가설은 같은 초기 가중치와 공통 관측에서 정책 첫 Tanh 포화 비율이 평균20퍼센트포인트 이상 감소하는지 별도로 측정한다. 수치 기준만 통과해도 성능 채택으로 보지 않는다. 성능 실패 시 다음 진단으로 돌아가며 카드 확대나 학습량 증액을 자동 진행하지 않는다.

완료 증거: 동일 상태의 인코딩/마스크/보상/trace 회귀, 로드 불일치 거부, 실제 모델 스텝·업데이트·초기가중치, 모든 평가 행동 독립 재현, 해시와 자원 감사, 원래 판정 기준에 따른 보고.
