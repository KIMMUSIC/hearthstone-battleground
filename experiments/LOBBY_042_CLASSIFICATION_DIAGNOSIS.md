# 042 — 모방 학습의 행동별 오류 진단

041 독립 감사가 통과했지만 개발 일치율79.25–79.56%, 평균순위 개선0.975, 상위4위5%로 두 사전 기준이 모두 미달했다. 기준을 바꾸거나 학습량을 늘리지 않고 저장 모델의 행동 분류 오류를 조사한다.

입력은 runs/lobby-041-local-r1의 고정 소스, 초기/최종3모델, train.npz(10,752행), dev.npz(2,236행), 최종60경기 trace다. 학습이나 모델 수정 없이 CPU1로 읽기 전용 진단한다. 예약 최종 평가 세트는 사용하지 않는다.

1. train/dev 각각 실제 마스크 예측으로 정확도, NLL, macro 행동별 정확도, 혼동 행렬을 재계산한다. 다수 행동의 높은 일치율이 드문 행동 실패를 가리는지 행동별 표본수와 오류 기여도를 함께 보고한다.
2. dev에서 모델3개의 공통 오류를 집계한다. END_TURN 조기/누락 예측, 구매 슬롯 혼동, 배치/판매/발견/업그레이드 등 의미별 오류를 분리한다. 액션 의미는 frozen 액션 계약에서 가져온다.
3. 최종60경기를 고정 소스로 재생하고 매 상태의 기존 heuristic 행동과 모델 행동을 비교한다. teacher trajectory의 분류 일치율과 learner가 실제 방문한 상태의 일치율을 구분한다. 반환 trace와 매 행동/순위가 일치하고 보존·완주·입력 불변을 검사한다.

출력은 새 experiments/diagnostics/lobby042_classification.json이며 기존 파일을 덮어쓰지 않는다. 전체 표본수와 분모, seed별 결과, 데이터·모델 해시, frozen 불변을 기록한다. 혼동 행렬 합계와 의미별 집계를 경계 테스트로 확인한다.

다음 분기는 결과를 보고 별도 명세한다. 다수 행동 편향이 핵심이면 동일 업데이트 예산의 샘플링/손실 가중치 비교를 검토한다. train/dev 차이가 크면 일반화, teacher/learner 상태 차이가 크면 방문 상태 분포를 우선 조사한다. 해당 진단만으로 원인 확정 또는 성능 개선을 주장하지 않는다. 카드 확대·새 의존성·예산 증액은 보류한다.
