# 036 — 관측 스케일과 보상 전달의 읽기 전용 진단

035는 상대 혼합으로 학습 순위가 다양해졌지만 세 seed 모두 공통 평가 개선이 0이었다. 다음 변경을 고르기 전에 저장된 모델의 수치 상태를 측정한다.

대상은 `runs/lobby-035-local-r1`의 6개 초기/최종 정책이다. 기존 개발 seed 20001..20020에서 heuristic 행동으로 만든 동일 관측 코퍼스를 모든 모델에 사용한다. 원본 입력과 모델 SHA256 및 코퍼스 해시를 기록하고 frozen source의 엄격한 호환 검사를 유지한다. CPU1, 실행 180초 이내, 새 학습·의존성·모델 수정 없이 수행한다.

측정 항목은 관측 필드별 절댓값 범위, 정책 및 가치 네트워크 첫 Tanh 층에서 절댓값 0.95 이상인 활성 비율, 실제 gamma/GAE lambda/rollout 길이다. 종국 TD 신호 한 항의 거리별 계수 `(gamma * lambda)^distance`는 분석식으로 표시한다. 전체 실제 advantage나 정책 품질의 측정값으로 표현하지 않는다.

포화 비율과 큰 입력이 관측되면 정규화를 후속 단일 변수 가설로 검토할 수 있다. 포화만으로 원인을 확정하거나 정규화 효과를 주장하지 않는다. 보상 계약과 상대 구성을 동시에 변경하지 않는다. 후보 비교는 이 진단 결과 뒤에 seed·예산·채택/반증 기준을 별도 고정해야 한다.

완료 기준: 재실행 가능한 진단 스크립트, 새 출력 덮어쓰기 거부, 입력/모델 불변 확인, 실제 수치와 제한사항, 후속 가설 또는 근거 부족 판정. 미사용 검증 seed 22001..22100과 기존 예약 최종 seed는 접근하지 않는다.
