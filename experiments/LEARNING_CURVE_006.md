# 학습량과 학습 seed 비교

005 파일럿 원본을 Codex가 검증한 뒤 남은 8조합을 실행한다. 학습 함수 1.068초, 학습·160평가 감독기 8.565초, 샘플링 RSS 398,053,376bytes를 근거로 전체 300초, 개별 학습 60초, CPU 1스레드, RSS 2GiB, 새 출력 디스크 100MiB를 지정했다. RSS와 디스크 감시는 하드 상한 보장이 아니다.

| seed | 신규 학습량 |
| --- | --- |
| 7 | 2048, 8192 |
| 17 | 512, 2048, 8192 |
| 27 | 512, 2048, 8192 |

seed7·512는 보존된 005 결과를 사용한다. 모든 학습은 새 초기화에서 시작한다. 동일 seed의 서로 다른 학습량은 독립 반복 표본으로 세지 않는다. 각 모델의 초기/최종에 argmax와 정책 seeds11/22/33, 게임 seeds201–220을 적용한다. 006은 1,280평가게임, 005 포함 1,440게임이다.

검증된 `curve-005/scripts/learning_curve.py`와 `selection_probe.py`, snapshot-003 checkout 및 venv311을 그대로 사용한다. PPO rollout32/batch32/epoch1, 규칙·보상·상대·카드·관측을 고정한다. 예상 업데이트 수는 16/64/256이다. 새 클라우드 출력은 `/workspace/hsai-rebuild/curve-006`이다.

관련 8테스트와 Ruff는 005에서 통과했다. 실행 파일이 그대로이면 같은 게이트를 반복하지 않는다. 실패·시간 초과·디스크 초과면 캠페인을 중단하고 원본을 반환한다. 설치·삭제·기존 소스 수정은 하지 않는다.

반환 ZIP과 내부 모델 해시, 최종 업데이트 카운터, trace 합법성·확률·보상 및 요약 재계산을 확인한다. 같은 학습 seed의 초기 평가 일치도 비교한다. seed별 수치와 세 seed 평균·범위를 함께 보고한다. 유한한 고정 상대의 작은 환경에서 얻은 결과이며 실제 전장 실력이나 통계적 유의성을 주장하지 않는다.
