# 046 — 방문 상태 추가 후 오류 진단 초안

상태: 045 결과 대기 중. 결과와 독립 감사가 확인된 후 분기 및 명세를 확정한다.

목적은 학습 데이터 추가가 teacher 기본 상태·고정 collector 상태·새 모델 자기 방문 상태에 어떻게 전이됐는지 구분하는 것이다. 기존 045 산출물과 고정 모델을 읽기 전용으로 사용한다. 새로운 모델 학습, 카드 확대, PPO 연결은 포함하지 않는다.

같은 seed의 control/candidate 최종 모델을 같은 teacher 기본 학습 행과 같은 collector 추가 학습 행에 각각 적용한다. source별 micro/macro/NLL, 정답 행동 분포와 혼동 행렬을 보고한다. 이 두 코퍼스는 학습 데이터이므로 일반화 성적으로 부르지 않는다. teacher dev 분류와 최종 자기 방문 상태의 일치율은 별도 분모로 유지한다.

045 최종 120경기의 모든 저장 행동을 모델 예측과 대조하며 관측·합법성·카드 보존·순위·보상·trace를 재현한다. 라운드 1–3, 4–6, 7+의 teacher 일치율, 구매 슬롯 오류와 행동 종류 오류, 첫 불일치, 골드·손패·보드·티어 분포를 집계한다. 경기 길이가 다른 상태별 일치율을 순위 효과로 해석하지 않는다.

입력 모델/데이터/trace 해시를 실행 전후 비교한다. CPU1/1, 새 출력 JSON, 기존 파일 덮어쓰기 없음. 테스트는 source 행 경계, 클래스 분모, 반순위, 행동 종류/슬롯 분리, 변조된 trace 거부를 검증한다. 실행 결과에는 source별 분모와 모델별 경기 수를 포함한다.

045 후보 유지 기준을 통과하면 채택 범위를 현재 제한 환경의 개발 비교로 한정하고, 다음 별도 견고성 검증의 필요 조건을 정한다. 미달하면 기준을 보존하고, source별 오류가 뒷받침하는 단일 후속 가설만 제안한다. 반복 튜닝이나 예산 증액은 자동으로 진행하지 않는다. 개발 seed20001..20020은 반복 사용한 개발 세트이며 최종 holdout이 아니다.
